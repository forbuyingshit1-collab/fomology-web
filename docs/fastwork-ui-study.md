## Information architecture

FOMOLOGY owns learning: course discovery, the existing free course, resources, and editorial writing. Fastwork owns the commissioned-work inquiry. Learning is the primary call to action; Fastwork is an explicitly named external destination.

The homepage flow is invitation -> explore actual work -> available course -> writing -> learning/hiring choice. New paid courses can be added after content, availability, price, and payment flow are confirmed. The redesign does not turn the existing free course into a paid offer.

## Design

White canvas, ink typography, red interaction accents, thin neutral borders, restrained shadows, rounded work surfaces, local Thai fonts. Preserve semantic HTML, visible focus, mobile menu trapping, reduced-motion behavior, and original course progress. Essential content is visible without JavaScript; JavaScript enhances practice selection and video dialogs.

## Evidence scope

Rendered pages, DOM, and accessibility snapshots establish visible structure and content. They do not establish Fastwork's hidden server architecture or implementation ownership. This is an independently implemented adaptation of interaction principles.
