# Keep the initial showcase static

The initial release will use Next.js, TypeScript, and Tailwind as a static export deployed to Cloudflare Pages, with the supplied media remaining on Cloudinary. Supabase, authentication, a database, Workers API code, Queues, and R2 are deferred until FOMOLOGY Lab development begins, preventing the future SaaS architecture from slowing or complicating the showcase launch.
