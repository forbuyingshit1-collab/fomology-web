# Launch with a text first FLUX 3 First Win Course

FOMOLOGY will launch the Free Course as an ungated, text-first single page organized into three modules and ten short lessons, with optional deeper explanations, real FLUX.3 examples, a downloadable Codex Prompt Skill, and device-local progress. The first guided setup targets 30–45 minutes and ends with a downloaded 8–10 second vertical video with audio; later idea-to-generation runs target about 15 minutes. This supersedes ADR-0005's requirement for three video-led stages because complete owner-supplied written material and working examples can deliver an honest usable course before dedicated lesson videos exist.

## Consequences

Launch readiness is based on complete written lessons, working links, the tested Skill package, checklists, and the Guided Project rather than requiring a video URL for every lesson. FOMOLOGY Lab remains a separate non-interactive preview, and the static site never receives API keys, prompts, or generated videos.
