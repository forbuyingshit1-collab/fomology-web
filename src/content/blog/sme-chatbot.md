# การใช้ Chat Bot แอดมินใน SME ขนาดเล็ก

## ค่าใช้จ่ายในการใช้ AI แทนมนุษย์ยังแพงอยู่ไหม?

“ค่าใช้จ่ายในการใช้ AI แทนมนุษย์ยังแพงอยู่ไหม?” เป็นคำถามที่ผมสงสัยขึ้น เมื่อรุ่นพี่ที่รู้จักกัน บ่นให้ฟังว่ากำลังปวดหัวกับการหาจ้างแอดมินมาตอบแชทลูกค้า ด้วยความที่ผมกำลังอินกับ AI มาก ๆ ในช่วงนี้ เลยยุไปว่า “ทำไมพี่ไม่ลองใช้ AI ดูล่ะ เดี๋ยวนี้มันฉลาดและใช้ง่ายแล้วนะ”

รุ่นพี่ผมทำหน้างงและบอกว่า “ร้านพี่ไม่ได้ใหญ่ขนาดนั้น มันแพงไปเดี๊ยวค่อยทำ”

ทำให้ผมรู้ว่าหลายคนยังติดภาพจำว่า AI เป็นเรื่องขององค์กรใหญ่และต้องใช้เงินมหาศาล ด้วยความอยากรู้อยากลอง ผมจึงรับอาสาทำโปรเจกต์นี้จากรุ่นพี่ โดยตั้งเป้าหมายท้าทายตัวเองไว้ 3 ข้อ:

ต้องถูก!: มองหาเครื่องมือฟรีหรือถูกที่สุด แต่ต้องมีประสิทธิภาพ

ต้องง่าย!: เจ้าของร้านต้องอัปเดตราคาหรือสินค้าเองได้ง่ายๆ (เพราะราคาสินค้าเปลี่ยนบ่อย)

UX ต้องดี!: ต้องใช้งานง่าย ปลอดภัย และดูน่าเชื่อถือ เพื่อให้ลูกค้า (รวมถึงผู้สูงอายุ) กล้ากดสั่งซื้อ เพราะคนแก่กลัวแสกมเมอร์เกิ๊น

ก่อนจะเริ่ม ผมสำรวจตลาด Chatbot สำเร็จรูปหลายเจ้า (ผมชอบ Chatbase มาก ไว้เดี๊ยวมาทำรีวิว) แต่ราคารายเดือน 1,500 บาทแลกกับ 1,500 ข้อความถือว่าแพงเกินไป สำหรับโจทย์นี้ ผมเลยได้โอกาสลองวิชาใหม่ที่ลงคอร์สเรียนมา

ผมเลือกน้อง n8n ลูกรัก เป็นตัวควบคุมระบบทั้งหมด เพราะมัน Lean สุดๆ และแทบจะฟรีถ้าเรา Self-host เอง ตอนแรกผมกะจะเปิดคอมทิ้งไว้ 24 ชม. เพื่อรันระบบ แต่พี่เขาเบรกว่า “ค่าไฟน่าจะแพงกว่าค่าเช่า Server นะ M 555555” เลยต้องเช่า VPS ราคาแค่ 200 กว่าบาทต่อเดือน เอาล่ะ โดนละเดือนละ 200

และต้องจ่าย AI รายเดือนที่จะเชื่อมกับระบบอีก ตอนเลือก AI ผมลังเลมากตอนนี้ตลาดแข่งกันโหดมากไม่รู้จะเลือกใครดี ระหว่าง ChatGPT, Gemini และ GLM 4.7 (ของจีน) จริงๆ อยากฉีกไปใช้ของจีนเลย แต่สรุปได้ว่า

GLM 4.7: ถูกจริง แต่ไม่ขนาดนั้น + Dashboard รายงานผลใช้งานยาก

ChatGPT: เก่งแต่ราคายังแรงถ้าใช้เยอะ

หวยมาออกที่ Gemini เพราะราคาและประสิทธิภาพสมดุลที่สุด แถมการผูกบัตรจ่ายเงินก็ดูน่าเชื่อถือและสบายใจกว่าเจ้าอื่น ๆ ถูกมากนะ ตกประมาณ 0.007–0.03 บาท ต่อข้อความ คุยจนมันเพ้ออ่ะ

เครื่องมือครบก็ได้เวลา Debug เอ่ย!! วางแผนงานแล้ว

## เริ่มจาก workflow ที่เรียบง่าย

ผมเริ่มจาก ท่ามาตรฐาน Basic ที่สุดเลย คือสร้าง Webhook รับข้อความจาก Facebook -> ส่งให้ AI -> ตอบกลับ

บอทคุยรู้เรื่องแล้ว ง่ายมาก!! แต่เอาข้อมูลร้านใส่ใน System prompt มันยากเกิน คนอื่นทำไม่ได้ แก้ไม่ดีเดี๊ยวบอทพังอีก ใช้ยากเกินเลยนำมาสู่

## Phase 2 / เชื่อมข้อมูลร้าน

Phase 2: เชื่อมสมองกับบัญชี (Google Sheets) เพื่อให้บอทรู้ราคา ผมเชื่อม Google Sheets เข้าไป เพราะเป็นเครื่องมือที่พี่เจ้าของร้านคุ้นเคย แก้ไขง่ายสุดๆ + เพิ่ม Node คลีนข้อมูลและกันสแปมไปด้วย

Flow: Webhook -> AI -> อ่าน Sheet -> ตอบ

ปัญหา: ทีนี้ช้าเลย บอทกลายเป็น introvert คิดก่อนพูด วิ่งไปอ่าน Sheet ทุกรอบ ทำให้บอทตอบช้า จริงๆ มันก็ใช้ได้แล้วแหละ แต่ด้วยความสงสัย เลยไปหาวิธีแก้มา ได้ไอเดียใหม่เป็น

## Phase 3 / จัดการความรู้ด้วย RAG

Phase 3: รวดเร็วและแม่นยำด้วย RAG เพื่อแก้ปัญหาความอืด ผมเปลี่ยนมาใช้เทคนิค RAG (Retrieval-Augmented Generation)

ทำให้บอทมีความรู้เกี่ยวกับร้านอยู่ในตัวเองเลย และจะอัพเดตความรู้ตัวเองเมื่อเราแก้ไขชีทสั่งให้อัพ พอไม่ต้องวิ่งไปหาข้อมูลก้เลยตอบไวขึ้น ทีนี้เลยทั้งตอบไว และแก้ง่ายแล้ว!!

Flow ใหม่: Webhook -> AI -> RAG (ดึงข้อมูลเฉพาะที่ต้องใช้) -> ตอบ

ผมเขียน Workflow เพิ่มว่า “ถ้ามีการแก้ราคาใน Sheet ให้ไปอัปเดตใน RAG ทันที” เท่านี้บอทก็ตอบไวและข้อมูลเป๊ะสุดๆ

แค่บอทตอบลูกค้าได้ แล้วมันเรียกว่า Automation ได้ไม่เต็มปาก ผมเลยเพิ่มงานให้ตัวเอง

## Phase 4 / ส่งต่องานให้แอดมิน

Phase 4: ผู้ช่วยแอดมิน ผมไม่อยากให้แอดมินต้องมานั่งไล่อ่านแชทเพื่อจดออเดอร์ อยากให้นอนเฉยๆ เลยได้ไอเดียเพิ่มระบบ “สรุปออเดอร์”

Logic: ถ้า AI ปิดการขายได้ -> ส่งสรุปยอด (ชื่อ/ที่อยู่/สินค้า) เข้ากลุ่ม Telegram ทันที

แอดมินแค่นั่งรอดูมือถือ ถ้ายอดเด้งก็เตรียมแพ็คของได้เลย

พอระบบหลังบ้านนิ่ง ผมเริ่มมาโฟกัสที่ประสบการณ์ลูกค้า (UX) ปัญหาคลาสสิกคือ “Prompt Engineering ที่ไม่มีวันจบ” เรามักจะพยายามเขียนดักว่า ถ้าลูกค้าพิมพ์ 1 ให้ตอบ A, พิมพ์ 2 ตอบ B ซึ่งมันแก้ที่ปลายเหตุ และดูไร้ที่สิ้นสุด หลังจาก research ไปสักพักผมก็คิดได้ว่า:

“แทนที่จะเดาใจลูกค้า เรายัดคำพูดให้เขาเลยดีกว่า”

ผมพัฒนาให้บอทส่งข้อความแบบ Carousel (การ์ดรูปภาพ) ที่มีปุ่มกดชัดเจน เช่น:

สิ่งที่ได้:

ลูกค้าเห็นภาพสินค้าชัดเจน น่าซื้อ

ลูกค้าไม่ต้องพิมพ์เอง แค่จิ้มปุ่ม

บอทได้รับคำสั่งที่แม่นยำ 100% (ไม่ต้องเดา)

ผมแยก Workflow ของ Carousel ออกมาต่างหาก เพื่อประหยัด Token และทำให้ระบบเบาขึ้น

ผมยังเพิ่มฟีเจอร์ให้แอดมินสามารถพิมพ์คำสั่งพิเศษ (เช่น /Start หรือ /Menu) เพื่อเรียก Carousel ตัวนี้ออกมาโชว์ลูกค้าได้ตามจังหวะที่เหมาะสม โดยล็อกรหัสไว้ว่าต้องพิมพ์ถูก 100% บอทถึงจะทำงาน เพื่อกันบอทรวน

## 🎯 บทสรุป

จากคำถามเล่นๆ ว่า “AI แพงไหม” สู่โปรเจกต์ AI Automation เต็มรูปแบบที่ช่วยให้ร้านของคุณพี่ปิดการขายได้ตลอด 24 ชั่วโมง โดยมีต้นทุนเพียงเดือนละไม่ถึง 1000 บาท

โปรเจกต์นี้พิสูจน์ให้เห็นว่า AI ไม่ใช่เรื่องไกลตัว หรือเรื่องของคนรวย แต่เป็นเครื่องมือที่ SME เล็กๆ ก็เข้าถึงได้ ถ้าเรารู้จักเลือกใช้เครื่องมือให้ “ถูก ง่าย และ ดี”
