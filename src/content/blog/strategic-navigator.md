# สร้าง The Strategic Navigator : ผู้ช่วย AI วิเคราะห์คริปโตส่วนตัวด้วย n8n

โปรเจคนี้ ผมเริ่มจากความสนใจใน Openclaw แต่พอมาลองวาง Workflow จริงๆ ก็เห็นภาพว่าจริงๆ แค่ n8n ก็เพียงพอแล้ว เลยมาแชร์ไอเดียที่ใช้ทำครับ (ส่วน Openclaw เดี๊ยวมาทำโปรเจคใหม่)

เป้าหมายของโปรเจกต์นี้: เกริ่นก่อนว่าผมเป็น Trader ที่ชื่นชอบ technical เป็นทุนเดิม และมี pattern การดูกราฟในตอนเช้าที่ค่อนข้างชัดเจน ซึ่งบางครั้งง่วงนอน จึงต้องการสร้างระบบ Automation ที่จะรวบรวมข้อมูลที่ผมอ่านประจำ แล้วสรุปเป็น Morning Briefing สั้นๆ ส่งตรงเข้า Telegram ทุกเช้า

เริ่มจากแกะไอเดียพฤติกรรมในตอนเช้าของผมก่อน ผมสังเกตและพบว่า ผมจะเช็คไล่ไปแบบนี้ ราคา BTC , Fear & Greed Index , Liquidation Heatmap , ETF Net Flow , CDC Action Zone, RSI Status และสุดท้ายก็คือข่าวประจำวัน ถ้าใครใช้ประมาณนี้ก็โหลดไปได้เลยครับ 😘

เพื่อให้ระบบทำงานได้เสถียร ยืดหยุ่น และประหยัดค่าใช้จ่าย ผมเลือกใช้ n8n เป็นแกนกลางในการเชื่อมต่อ (Orchestrator) โดยแบ่งการทำงานออกเป็น 4 ส่วนหลัก:

## 01 / Data Ingestion

Data Ingestion ผมไม่ได้ให้ AI ไปเสิร์ชข้อมูลเองสะเปะสะปะ แต่ใช้ n8n วิ่งไปดูดข้อมูลจากแหล่งที่เชื่อถือได้ (Single Source of Truth) ผ่าน API โดยตรง:

[ตัวอย่างโค้ด/Workflow export จากต้นฉบับถูกพักไว้เพื่อตรวจข้อมูลภายในก่อนเผยแพร่]

HTTP Request Node (Binance API): ดึงราคา BTC สดๆ เพื่อความแม่นยำ

[ตัวอย่างโค้ด/Workflow export จากต้นฉบับถูกพักไว้เพื่อตรวจข้อมูลภายในก่อนเผยแพร่]

HTTP Request Node (Alternative.me): ดึงค่า Fear & Greed Index เพื่อประเมินจิตวิทยาตลาด

[ตัวอย่างโค้ด/Workflow export จากต้นฉบับถูกพักไว้เพื่อตรวจข้อมูลภายในก่อนเผยแพร่]

RSS Read Node (Cointelegraph): ดึงพาดหัวข่าว Top 3 ล่าสุด เพื่อให้ AI เข้าใจบริบท (Context) ของสิ่งที่เกิดขึ้นในโลก

หากต้องการใช้แค่บางตัว Copy ไปได้เลยครับ 😘

## 02 / Trading Memory

2. The Trading Memory อันนี้ผมว้าวมาก ตอนแรก นึกว่าจะต้องใช้ท่ายากกว่านี้ แต่ดันไปเจอวิธีจากช่อง AIPathways แล้วตาสว่างเลยครับ(ตามไปดูวิธีเชื่อม TradingView ได้) ผมใช้ CDC Action Zone V3 และ RSI นะตั้งกันตามสไตล์ได้เลย หลังจากนั้น ใช้ TradingView ยิง Webhook เฉพาะตอนที่กราฟเกิดการตัดกัน (Cross) เท่านั้นไม่ได้ส่งข้อมูลตลอดเวลา

https://www.youtube.com/@AIPathwaysChannel

เพิ่มเติมเทคนิคที่ใช้: ผมใช้ Google Sheets Node ทำหน้าที่เป็น Database ขนาดย่อม เมื่อกราฟใน TradingView เกิด Action มันจะยิง Webhook ข้ามมาหา n8n เพื่ออัปเดตสถานะ (เช่น เปลี่ยนจาก Blue เป็น Red) ทับลงใน Sheet โดยใช้โหมด Update Row อ้างอิงจากคอลัมน์ชื่อเหรียญ (Asset) ทำให้เรามี State ล่าสุดของ Technical Signal เก็บไว้เสมอครับ

## 03 / Data Aggregator

3. Data Aggregator Code Node: ก่อนจะส่งข้อมูลให้ AI ผมใช้ JavaScript เล็กน้อยใน Code Node เพื่อจับข้อมูลทั้ง 4 สาย (ราคา, อารมณ์ตลาด, ข่าว, และข้อมูลจาก Google Sheets) มามัดรวมกันเป็นโครงสร้าง JSON ก้อนเดียวครับ อันนี้ใช้ KIMI 2.5 ช่วยเขียนให้ครับ น้องฉลาดมาก

[ตัวอย่างโค้ด/Workflow export จากต้นฉบับถูกพักไว้เพื่อตรวจข้อมูลภายในก่อนเผยแพร่]

## 04 / AI Agent

4. AI Agent Node (Gemini): ผม Prompt ให้ AI เป็น นักกลยุทธ์การลงทุน ให้ AI วิเคราะห์ด้วยว่าคิดเห็นยังไง (เช่น ข่าวร้ายกดดันตลาด แต่ RSI เกิด Bullish Divergence) เพื่อใช้อ้างอิงเนื่องจาก Gemini ไม่แพงและฐานข้อมูลของ Google เยอะอาจจะได้ไอเดียดีๆ บ้าง ย้ำว่า บ้าง นะ ฮาๆๆ

Telegram Send Node: ใช้ Bot Token และ Chat ID เพื่อยิง Report ผลลัพธ์กลับมาที่แชทส่วนตัว พร้อมจัด Layout ให้อ่านจบเข้าใจได้ใน 10 วินาที
