# ผมทำแอพ รายรับ-รายจ่าย ที่ทำมาแค่เพื่อผม

สร้าง n8n ให้เป็นผู้ช่วยส่วนตัวของคุณ

ทำแอปรายรับ-รายจ่ายเองดีกว่าใช้ของคนอื่น ไม่ใช่เพราะฟังก์ชันที่ล้ำกว่า แต่เป็นเพราะจะมีแค่ฟังก์ชันที่เราน่าจะได้ใช้จริงๆ

ผมเป็นอีกคนหนึ่งที่อินเรื่องการเงินมากๆ และเอาจริงฟังไลฟ์โค้ชคนไหน ก็มีแต่คนพูดว่าให้ทำรายรับ-รายจ่ายซะ แล้วการเงินจะดีขึ้น โหลดตลอดแต่เงินไม่เคยเพิ่ม มีแต่เมมที่จะเต็ม ฮาๆๆ

แต่ผมเช่า VPS Hostinger อยู่เลยคิดว่า เห้ย เราสร้างแอปสำหรับเรา ที่เข้าใจแค่ภาษาของเราได้หนิ เช่น ผมพิมพ์ “แฟ 50” และมันบันทึกแยกหมวดให้ได้ว่าเป็น รายจ่าย ค่ากาแฟ 50 บาท นี่ผมก็ฟินละ (ขก. มาก ฮาๆ) เลยเกิดเป็นโปรเจคนี้ขึ้นมาครับ

“ผมคิดว่า 80% ของแอปจะหายไป ทำไมผมต้องใช้ My Fitness Pal ในเมื่อ Agent ของผมรู้อยู่แล้วว่า ผมกำลังจะตัดสินใจแย่ๆ เรื่องอาหาร”

ก่อนเริ่ม ผมจะบอกว่าผมเห็นด้วยกับประโยคนี้มาก พอเริ่มพัฒนาบอท ก็เห็นภาพว่าอนาคตจะพัฒนาบอทให้เป็น J.A.R.V.I.S. ส่วนตัวของตัวเองเลยก็ได้หนิ (จริงๆ Openclaw ก็เกือบเรียกว่า J.A.R.V.I.S. ได้แล้วไหมนะ)

มาพูดเรื่องโปรเจคดีกว่า คอนเซปต์เริ่มแรก ไม่มีอะไรยากก็แค่นำวิชาที่เรียนมาประกอบจากปัญหาส่วนตัวของตัวเอง ทำให้ผมสรุปได้ว่า:

ผมต้องการ Tracker ที่แค่ พิมพ์แชทบอก หรือ ส่งรูปสลิปโอนเงิน เข้า LINE ระบบจะใช้ AI คิด วิเคราะห์ จัดหมวดหมู่ และบันทึกลง Google Sheets ให้แบบอัตโนมัติ พร้อมอัปเดต Financial Dashboard ให้ดูแบบ Real-time เท่ป่ะ ฮาๆๆ

## โปรเจคนี้ทำงานยังไง? (System Architecture)

ผมออกแบบระบบนี้ให้ทำงานอัตโนมัติผ่านเครื่องมือหลักๆ คือ LINE, n8n, Gemini AI และรันเว็บบน GitHub Pages * จุดรับข้อมูล (LINE Official Account): ทำหน้าที่เป็นหน้าบ้านให้เราคุยด้วย (น้อง M) เราสามารถพิมพ์ข้อความภาษาคนง่ายๆ เข้าไปได้ หรือส่งรูปสลิปธนาคารเข้าไปให้บอทอ่านก็ได้

สมองกลประมวลผล (n8n + Gemini AI): เป็นหัวใจหลัก เมื่อ n8n รับข้อความหรือรูปภาพมา จะทำงาน:

กรณีพิมพ์ข้อความ: n8n จะส่งข้อความให้ Gemini วิเคราะห์ว่าเป็น “รายรับ” หรือ “รายจ่าย” พร้อมแยกหมวดหมู่และยอดเงิน

กรณีส่งรูปสลิป: n8n จะใช้ Gemini สกัดข้อความจากรูป (OCR) เพื่อดึงยอดเงิน และอ่านโน้ตบันทึกช่วยจำเพื่อจัดหมวดหมู่ให้ แถมยังอัปโหลดรูปสลิปไปเก็บแบคอัปไว้ใน Google Drive ให้เราโดยอัตโนมัติด้วย

ฐานข้อมูล (Google Sheets): หลังจาก AI ย่อยข้อมูลเป็น JSON เสร็จ n8n จะนำข้อมูลมากรอกลง Sheet โดยอัตโนมัติ (ถ้าเป็นสลิปจะแนบลิงก์รูปจาก Drive ไว้ในช่องหมายเหตุให้ด้วย)

[วิดีโอสาธิตจากต้นฉบับถูกพักไว้เพื่อตรวจข้อมูลส่วนตัวก่อนเผยแพร่]

สรุปผล (LINE Message & Web Dashboard): ท้ายสุดบอทจะสรุปรายการที่บันทึกตอบกลับมาใน LINE และเราสามารถกดเข้าลิงก์ไปดู Web Dashboard ที่เขียนด้วย HTML/JS ล้วนๆ รันบน GitHub Pages (โฮสต์ฟรีจ้า!) ที่ดึงข้อมูลจาก Sheet มาพล็อตกราฟสรุปยอดใช้จ่ายรายวัน รายเดือน ได้อย่างสวยงาม

## วิธีนำ Workflow นี้ไปใช้งานต่อ (Quick Setup)

สำหรับใครที่ใช้ n8n อยู่แล้ว สามารถโหลดไฟล์ n8n Workflow ไปรันต่อได้เลยครับตั้งค่า Credentials: ใน n8n ให้เชื่อมต่อ API Key ของคุณให้เรียบร้อย หลักๆ จะมี:

LINE Messaging API (สำหรับรับส่งข้อความ)

Google Gemini API (แนะนำให้ใช้โมเดล Gemini 2.5 Flash-lite หรือตัวที่ใกล้เคียงครับ เร็วและประหยัด)

Google Workspace (Drive & Sheets OAuth2)

เตรียม Google Sheets: สร้างไฟล์ Sheet ว่างๆ ขึ้นมา 1 ไฟล์ แล้วตั้งชื่อหัวคอลัมน์ให้ตรงกับที่ระบบต้องการ คือ Date, จำนวนเงิน, รายรับ/รายจ่าย, กลุ่ม, และ หมายเหตุ จากนั้นเอา Sheet ID ไปใส่ใน Node “Append row in sheet”
