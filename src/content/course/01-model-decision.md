## บทนี้คุณจะได้อะไร

คุณจะเลือกโมเดลจาก **เป้าหมาย คุณภาพ ปริมาณ และต้นทุนที่รับได้** แทนการถามว่าโมเดลใด “ดีที่สุด” และตั้งเป้า Guided Project ให้ชัด: คลิปร้านกาแฟแนวตั้ง 8–10 วินาทีพร้อมเสียง

## เข้าใจใน 1 นาที

AI Video ทุกครั้งคือการตัดสินใจที่มีต้นทุน โมเดลคุณภาพสูงเหมาะเมื่อภาพหนึ่งชิ้นมีผลต่อแบรนด์หรือการเล่าเรื่อง ส่วนงานจำนวนมากอาจให้ความสำคัญกับต้นทุนต่อคลิปมากกว่า เอกสารต้นทางยก MiniMax/Hailuo เป็นตัวเปรียบเทียบ แต่ราคาหรือความสามารถเปลี่ยนได้ จึงไม่ใช้ตัวเลขเก่าตัดสินใจ

สำหรับคอร์สนี้เราเลือก FLUX.3 เพราะต้องการฝึกการกำกับ Action, Camera, Audio และ Final Image อย่างเป็นระบบ ไม่ได้หมายความว่า FLUX.3 เหมาะกับทุกงาน

## ทำตามทีละขั้น

1. เขียนเป้าหมายหนึ่งประโยค: “ทำคลิปเปิดร้านกาแฟที่ดูอบอุ่นและจบด้วยแก้วกาแฟพร้อมเสิร์ฟ”
2. เลือกช่องทาง: วิดีโอแนวตั้งสำหรับ Reels, Shorts หรือ TikTok
3. ยอมรับขอบเขต: การ Generate จริงใช้เครดิต และผลลัพธ์อาจต้องปรับ
4. กำหนด Stop rule: ทำ Dry Run ก่อนเสมอ และไม่กดซ้ำอัตโนมัติเมื่อเกิด Error, Moderation หรือเครดิตไม่พอ
5. เก็บราคาปัจจุบันจากหน้า Provider ตอนจะ Generate ไม่คัดลอกตัวเลขราคาไว้ใน Prompt

## ตัวอย่างไม่ดี / ดีขึ้นอย่างไร

**ไม่ดี:** “ใช้โมเดลที่ดีที่สุด ทำคลิปไวรัลให้หน่อย” — ไม่มีผู้ชม งานที่ต้องเกิด หรือเพดานต้นทุน

**ดีขึ้น:** “ต้องการวิดีโอแนวตั้ง 8 วินาทีสำหรับร้านกาแฟ เปิดด้วยเจ้าของร้านเปิดบานไม้และจบที่กาแฟเย็นหนึ่งแก้ว พร้อมเสียงบรรยากาศ ไม่มีบทพูด ฉันจะตรวจ Draft HD หนึ่งครั้งก่อนตัดสินใจต่อ”

## ลองทำ

เติมประโยคนี้ให้ครบ แล้วเก็บไว้ใช้ในบท 7:

```text
ฉันต้องการทำวิดีโอ __________ สำหรับผู้ชม __________
ความสำเร็จคือผู้ชมเห็น __________ และคลิปจบที่ __________
ฉันยอมรับว่า Generation มีค่าใช้จ่าย และจะตรวจ Dry Run ก่อน Submit ทุกครั้ง
```

## เช็กก่อนผ่าน

- เป้าหมายวัดจากสิ่งที่คนดูเห็น ไม่ใช่คำว่า “สวย” อย่างเดียว
- รู้ว่าคลิปนี้ใช้ช่องทางใดและเป็นสัดส่วน 9:16
- เข้าใจว่า Draft ก็เป็น Paid Generation เมื่อ Submit
- พร้อมหยุดและแก้ข้อมูลก่อน ไม่กด Generate ซ้ำเพื่อเดา
