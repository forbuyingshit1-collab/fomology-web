# FOMOLOGY: Learn & Make

Design authored from the user's requested redesign, existing content, and reference research. This is an implementation brief, not a verbatim interview.

## User direction

- Vibe: “ขาวคลีน ตัวอักษรดำ แต้มสีแดง FOMOLOGY”. Reference: Fastwork's selling opening and profile-showcase section.
- Journey: the user wants the website to sell courses and Fastwork to take commissioned work. Authored sequence: see possibilities, explore the teacher's real work, enter the existing free course, read field notes, choose learning or hiring.
- Energy: authored calm opening, rich but contained work explorer, quiet readable course details, decisive close.
- Feeling and memorable moment: authored curiosity -> agency -> confidence -> familiarity -> resolve. The work explorer connects each selected practice to an honest, available learning destination.
- Signature: authored “See it, then learn it”: switching practice changes the actual selected work and the relevant learning link together. This is a functional explorer, not an embedded Fastwork profile.
- Aesthetic: the user explicitly chose clean white, black typography, and the existing red brand. No cinematic scroll lock or generated scenery.
- Structure: authored separate natural-flow sections, with a centered opening and asymmetric explorer. Reuse the real existing course, blog, and original work.
- Assets: existing FOMOLOGY logo, original Cloudinary video posters and full clips, local article covers. No third-party portfolio imagery is copied. No new generated media.

## Feeling curve (before section planning)

1. Curiosity: original project cards surround a clear invitation to learn.
2. Agency (the peak): choose AI Video, Websites, or Automation; a large work example and its learning next step change together.
3. Confidence: one course that can actually be opened, with its real three modules, ten lessons, and first-run guidance.
4. Familiarity: real writing and experiments from the teacher.
5. Resolve: a clear choice between learning on FOMOLOGY and commissioning through @anan on Fastwork.

Peak sentence: “เลือกงานที่ชอบ แล้วมีทางไปเรียนรู้ต่อได้เลย”.
Tell-someone sentence: “It's the site where you can explore what the teacher actually makes, then choose where to start learning.”
No authored dead scroll, pinned sections, countdown, or automatic audio.

## Grammar and layer contract

Custom learning gallery: compact floating navigation; spacious invitation surrounded by real work; a selectable practice index; a complete course feature; field notes; a two-destination close. The collection is not a literal gallery grammar because a distinct invitation and course conversion are required. Bans: fabricated learner work, popularity counts, ratings, invented course prices, fixed scroll timelines, and decorative dashboards.

Other grammars: filmic one-shot and continuous world obstruct course navigation; chaptered editorial repeats the previous site; live surface misrepresents a learning site as a tool; typographic poster suppresses important work evidence; gallery/catalog forbids the requested distinct invitation; split stage gives the hiring path too much prominence; episodic scenes add unnecessary theatricality.

Hero planes: white canvas stays still; outer original-work cards move a few pixels at individual scroll rates; the central headline and CTA stay legible and stable. Mobile uses a compact project strip below the copy. Reduced motion retains a static, complete composition.

## Score

| Invitation | Layered original-work collage | Show the breadth of what can be made |
| Explore (peak) | Interactive practice index | Change work selection and relevant learning destination |
| Start learning | Static course feature and disclosure | Make the available course and syllabus concrete |
| Read | Quiet editorial links | Offer substantive alternate entry points |
| Choose | Asymmetric destination pair | Keep learning primary and hiring explicit |

The user's clean, simple direction takes precedence over the skill's cinematic device quota. No media generation or transcoding is needed. Scrollcraft preflight found no ffmpeg, no build-local playwright-core, and no KIE key; existing source assets and the connected REA browser scenario tool supply the applicable workflow.
